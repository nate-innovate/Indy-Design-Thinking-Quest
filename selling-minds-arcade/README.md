# Selling Minds Arcade

A review game for the *Selling Minds* advertising and propaganda unit (intermediate–advanced multilingual learners, English 1/2). Students name ad techniques, work with word choice, and critique ads.

Open `index.html` in a browser. It is one self-contained page; the only outside request is Google Fonts.

## Modes

| Mode | What students do | English 2 standard |
| --- | --- | --- |
| Lightning Round | Name as many ad techniques as possible in 60 seconds | ELA.E2.AOR.5.3 |
| Spot It | 10 ads, 4 choices each, with an optional hint | ELA.E2.AOR.5.3 |
| Word Lab | Connotation picks, hyperbole vs. literal, tap the weasel word | ELA.E2.AOR.8.1 |
| Ad Critic | Name the appeal, ask the exposing question, judge evidence, revise a weak ad for an audience | ELA.E2.AOR.4.1, 5.2, 5.3 |
| Term Cards | Flip cards for 19 techniques and 13 key words, with Spanish | Academic vocabulary |

All brands in the example ads are invented. Scores and technique mastery are saved in each student's own browser (`localStorage`).

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root. The arcade will then be at `https://nate-innovate.github.io/Indy-Design-Thinking-Quest/selling-minds-arcade/`.
